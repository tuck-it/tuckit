{% comment %} Restoring the open/closed state. This can't be done in base.html's pre-paint script — while is running, #main-content hasn't been parsed yet. Working around that by tagging a class on instead is exactly the pattern that produced the ob-open 360px ghost margin (a root class outliving its own element), so that route isn't used here. Being inline here means it runs during parsing — before first paint — and its lifetime matches the element's, so no ghost can be left behind. It does not persist the value itself — toggle doesn't bubble, so the global capture listener (base.html) owns that, which also means morph re-inserting this script never attaches a duplicate listener. Assigning the attribute is idempotent, so re-running it is safe. {% endcomment %}
