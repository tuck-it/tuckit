{% load web_extras %} {% comment %} The Edit-Area dialog, mounted in {% block overlays %} — outside #main-content, where a live morph cannot strip the inline display:none Alpine hides it with. Its two triggers stay in the header and reach it by window event (see _area_header.html). hx-target="#area-header" still resolves from out here: htmx matches the selector against the whole document, and the header it swaps is now purely the title block. Moving the dialog out of that target is in fact what lets the swap stay simple — the dialog is no longer collateral in its own save. Closing after a save goes out through the same window event that opens it, and for a reason worth spelling out: an hx-on handler is compiled in GLOBAL scope, so it cannot see Alpine's. The old `edit = false` in here silently assigned to a global of that name and never closed anything — the dialog only seemed to shut because it sat inside the swapped header and was destroyed along with it. Out here nothing destroys it, so the close has to be real. Context: area (target Area). {% endcomment %}
